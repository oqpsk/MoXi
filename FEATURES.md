# Features

| Capability | Status |
| --- | --- |
| Local Markdown files, drag-and-drop and file-path launch | Available |
| Focus reading, rich-text editing and Markdown source | Available |
| Headings, emphasis, lists, tasks, quotes, tables and code | Available |
| Document outline, find-all highlighting and text zoom | Available |
| Day and dark themes; native Acrylic with opaque fallback | Available |
| Relative local raster images | Available |
| UTF-8 / UTF-16, BOM and line-ending preservation | Available |
| Atomic save and external modification/deletion checks | Available |
| Unsaved-change prompts, draft recovery and window placement | Available |
| Front matter, HTML and unsupported structures | Preserved in source view |
| Math and Mermaid rendering | Not currently supported |
| Multiple documents or windows; other desktop platforms | Outside the current release |

The current release supports one document at a time, up to 16 MB. Rich-text editing may normalize Markdown formatting; unchanged documents retain their original bytes.
