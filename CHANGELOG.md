# Changelog

## Unreleased

- Render pasted Markdown as formatted text in the editing view; a list pasted at the end of an item continues that list, and code blocks still receive literal text.
- Place pasted syntax that needs source view at the caret, rather than at the end of the document.
- Keep typing responsive in large documents: whole-document serialization now waits for a pause, a save or a view change, and opening a file parses its Markdown once fewer.
- Keep the file's original final line break when saving rich-text edits.
- Refresh the product overview and contributor documentation; rewrite the README in Chinese.

## 0.1.7

- Open files in focus reading by default; new documents begin in editing mode.
- Refine formatting toolbar proportions and separator contrast.
- Enter editing from the footer logo before switching to source.

## 0.1.6

- Highlight all search matches and keep focus while navigating results.
- Stabilize the search panel and improve source-view highlighting.
- Simplify the window layout, improve the footer logo and brighten the day theme.
- Accept equivalent Markdown mark nesting during compatibility checks.

## 0.1.5

- Refine native window controls and status bar.
- Add a read-only focus preview that preserves the underlying editing state.

## 0.1.4

- Simplify global controls and refine toolbar alignment.

## 0.1.3

- Add coordinated day and dark themes.
- Improve task-list alignment and mixed-language typography.

## 0.1.2

- Add native Acrylic, responsive document layout and an introductory guide.

## 0.1.1

- Introduce the cyan visual identity and refine typography.

## 0.1.0

- Initial Windows Markdown reader and editor, with local file handling, rich-text and source views, encoding preservation, conflict checks and draft recovery.
